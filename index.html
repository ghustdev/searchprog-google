Todas as Tecnologias e Linguagens

JavaScript

JavaScript é uma linguagem de programação de alto nível, mais conhecida por seu uso em páginas web para criar interatividade. Hoje, também é amplamente utilizada no backend com Node.js, em aplicativos móveis e desktop.

    Linguagens/Tecnologias Relacionadas: HTML, CSS, React, Angular, Vue.js, Node.js, Express.js
Boas práticas:
  • Use sempre let ou const no lugar de var;
  • Prefira arrow functions quando possível;
  • Evite variáveis globais;
  • Comente apenas o necessário, escreva código legível;

React

React é uma biblioteca JavaScript de código aberto para construir interfaces de usuário (UI), especialmente para aplicações de página única (SPA). É baseado em componentes e mantido pelo Facebook.

    Linguagens/Tecnologias Relacionadas: JavaScript, JSX, Node.js, Redux, React Router, Next.js
Boas práticas:
  • Divida em componentes reutilizáveis pequenos;
  • Evite estados globais desnecessários;
  • Utilize chaves únicas em listas;
  • Mantenha o código dos efeitos (useEffect) limpo;

Python

Python é uma linguagem de programação de alto nível, interpretada, com uma sintaxe simples e legível. É extremamente versátil, usada em desenvolvimento web, ciência de dados, inteligência artificial, automação e mais.

    Linguagens/Tecnologias Relacionadas: Django, Flask, Pandas, NumPy, TensorFlow, PyTorch
Boas práticas:
  • Siga a PEP8 para formatação e nomes de variáveis;
  • Códigos e funções sempre bem documentados;
  • Prefira listas por compreensões;
  • Utilize virtualenv para ambientes isolados;

Node.js

Node.js é um ambiente de execução JavaScript que permite executar código JavaScript no lado do servidor. É ideal para construir APIs rápidas e escaláveis, microsserviços e aplicações em tempo real.

    Linguagens/Tecnologias Relacionadas: JavaScript, Express.js, NestJS, MongoDB, PostgreSQL
Boas práticas:
  • Use Promises e async/await;
  • Mantenha rotas organizadas em módulos;
  • Trate erros de forma centralizada;
  • Evite funções bloqueantes no servidor;

HTML & CSS

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criar páginas web, definindo sua estrutura. CSS (Cascading Style Sheets) é usado para estilizar e dar aparência às páginas web, controlando cores, fontes e layout.

    Linguagens/Tecnologias Relacionadas: JavaScript, Sass, Bootstrap, Tailwind CSS
Boas práticas:
  • Mantenha uma hierarquia clara de heading/semântica;
  • Use classes de CSS com nomes descritivos;
  • Evite estilos inline;
  • Centralize variáveis de cor no CSS;

Vue.js

Vue.js é um framework JavaScript progressivo para construir interfaces de usuário. É conhecido por sua curva de aprendizado suave, flexibilidade e excelente documentação.

    Linguagens/Tecnologias Relacionadas: JavaScript, Vuex, Pinia, Vue Router, Nuxt.js
Boas práticas:
  • Separe template, script e style nos arquivos .vue;
  • Utilize o sistema de diretivas do Vue;
  • Mantenha componentes pequenos e focados;
  • Siga convenções de nomes e diretórios;

Inteligência Artificial (IA)

Inteligência Artificial é um campo da ciência da computação dedicado a criar sistemas capazes de realizar tarefas que normalmente exigem inteligência humana, como aprendizado, raciocínio e percepção.

    Linguagens/Tecnologias Relacionadas: Python, R, TensorFlow, PyTorch, Scikit-learn, Redes Neurais
Boas práticas:
  • Garanta qualidade dos dados usados;
  • Documente as hipóteses do modelo;
  • Monitore vieses nos dados;
  • Utilize experimentação para refinar modelos;

API (Application Programming Interface)

Uma API é um conjunto de regras e definições que permite que diferentes aplicações de software se comuniquem. Ela atua como ponte para que um sistema acesse funcionalidades ou dados de outro de forma controlada.

    Linguagens/Tecnologias Relacionadas: REST, GraphQL, gRPC, JSON, HTTP, Node.js, Python
Boas práticas:
  • Documente todas as rotas e parâmetros;
  • Use versionamento nas APIs;
  • Evite retornar dados desnecessários;
  • Utilize autenticação adequada;

Docker

Docker é uma plataforma de código aberto que automatiza a implantação de aplicações dentro de contêineres de software. Contêineres empacotam o código e todas as dependências, garantindo que a aplicação funcione de forma consistente em qualquer ambiente.

    Linguagens/Tecnologias Relacionadas: Kubernetes, Linux, YAML, CI/CD, Go
Boas práticas:
  • Mantenha as imagens leves e seguras;
  • Use arquivos .dockerignore;
  • Utilize variáveis de ambiente;
  • Faça versionamento das imagens;

SQL (Structured Query Language)

SQL é uma linguagem de programação padrão usada para gerenciar e manipular bancos de dados relacionais. Com ela, é possível criar, consultar, atualizar e deletar dados.

    Linguagens/Tecnologias Relacionadas: PostgreSQL, MySQL, SQL Server, Oracle, SQLite
Boas práticas:
  • Sempre use parâmetros para evitar SQL Injection;
  • Nomeie tabelas e colunas com clareza;
  • Evite SELECT * em produção;
  • Utilize índices estrategicamente;
